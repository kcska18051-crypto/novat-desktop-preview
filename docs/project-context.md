## Как работать с пользователем

- Общение на русском, коротко; пользователь просил экономить токены.
- После изменений — реально проверять результат и присылать публичную ссылку.
- Не менять согласованные размеры, логотип, меню, шрифты и цвета при точечных корректировках.
- По новым визуальным решениям пользователь может сначала требовать картинку и согласование. Для подписки этот этап пройден, последний выбранный вариант реализован.
- Просьба «проверь» означает реальные проверки, не предположения по коду.
- Последующие прямые просьбы изменить и опубликовать превью выполнялись в этой же ветке.

## Афиша: история решений и текущая версия

Источники: [исходная афиша НОВАТа](https://novat.ru/afisha/performances/), [референс МХАТ](https://mxat.ru/afisha/).

### Десктоп

1. Первоначально переносилась исходная афиша для desktop-only согласования цветов; переключатели вариантов дизайна убраны.
2. Сохранены тонкие разделители; сцена, месяцы и даты сделаны бордовыми.
3. По референсу МХАТ карточка переделана: цифра даты, горизонтальное фото, сцена/время/возраст, название, описание, справа дирижёр/состав и покупка/ПК.
4. Названия и цифры уменьшены; картинки постепенно сделаны компактнее и более горизонтальными. `object-fit: cover`, пропорция около 2,1:1, максимум 170 px по высоте на широком экране.
5. Описания восстановлены из исходных данных. Если исходного описания нет, текст не выдумывался.
6. Возраст убран из надстрочной позиции возле названия, теперь в строке «БОЛЬШАЯ СЦЕНА · 19:00 · 16+».
7. Кнопка покупки компактная: бордовая с золотым текстом. По последней компоновке она и Пушкинская карта находятся справа по центральной горизонтальной оси блока.
8. Все десктопные блоки равной высоты. Последнее уплотнение — примерно на 21%: минимум сетки 196 px плюс вертикальные отступы по 16 px, полный ряд около 229 px вместо прежних 289 px. Проверялись ширины 1280, 1440 и 1920 px.
9. Подпись ссылки уточнялась: «Состав» → «Исполнители» → окончательно **«Состав исполнителей»**.
10. Первое название заменено на **«Ромео и Джульетта»** по просьбе пользователя. Остальные данные первого события (фото, описание, возраст, состав) при этой замене не менялись и остаются от исходной первой карточки.

### Месяц, фон, состав

- Один общий липкий заголовок «СЕНТЯБРЬ, СБ», автоматически меняется при прокрутке по текущей карточке в обе стороны.
- Не дублировать месяц возле каждой цифры даты.
- Только у этого меняющегося заголовка — полупрозрачная золотисто-бежевая полоса от границы sidebar до правого края контента. У верхних статических ссылок месяцев подложки нет: раннее неверное размещение исправлено.
- Кнопка переключения: «Бежевый фон» на белом, «Белый фон» на бежевом. Постоянного сохранения выбора нет.
- Состав открывается справа, на телефоне на всю ширину. Есть закрытие крестиком, Escape и фоном, удержание и возврат фокуса. Исправлены скачки страницы при блокировке скролла.

### Настоящий мобильный адаптив

- Исправлена ключевая ошибка: вместо `width=1440` в viewport теперь `width=device-width, initial-scale=1`. Раньше телефон уменьшал десктопную страницу примерно до 27%, а тест с простым уменьшением окна десктопа создавал ложное впечатление исправного адаптива.
- Проверено с мобильными профилями iPhone, Android, шириной 320 px и поворотом устройства. Это браузерная эмуляция, не физические устройства.
- Фиксированная шапка высотой **64 px**, бургер слева, новый официальный логотип по центру. Ранее высота 86 px уменьшена по просьбе пользователя.
- Логотип шапки — `assets/brandbook/novat-logo-1-rgb.png`; прозрачные поля учтены в CSS, исходный PNG не изменён.
- Полоса месяца закрепляется под шапкой: `top: 64px`.
- Карточки в одну колонку, высота по содержимому; равную высоту всех десктопных рядов на телефон не переносили.
- Есть фото, метаданные, название, описание, дирижёр, состав и удобная кнопка покупки с ПК под содержимым.
- Месяцы идут горизонтально, фильтр изначально свёрнут. Кнопки покупки минимум 44 px по высоте.
- Меню работает через native dialog, открытие/закрытие и сохранение позиции страницы проверены.

## Подписка: согласование, размеры и итог

Проблема: старая sidebar-форма терялась визуально, на мобильном подписку было трудно найти. Пользователь предложил оставить кнопку, открывающую панель справа, и потребовал сначала картинку.

История названия и визуала:

- «Новости НОВАТа» с яркой золотой заливкой и заголовком «Театр ближе» отклонены: рассылка не только про новости, оформление не подошло.
- Более лаконичное «Рассылка театра» тоже отклонено.
- «Получать анонсы» не выбрано окончательным названием.
- Пользователь предложил **«Подписаться на рассылки»**. Подтвердил картинку с контурной кнопкой и светлой правой панелью, попросил сохранить реальные логотип, меню, шрифты и размеры.

Текущее решение:

- Вместо старого ввода email в sidebar — кнопка «Подписаться на рассылки».
- На телефоне она есть в раскрытом меню и внизу афиши; мобильный вход подключён и на странице брендбука.
- Desktop drawer шириной 480 px, мобильный — на всю ширину и высоту доступного экрана; содержимое при необходимости прокручивается внутри.
- Заголовок: «Подписаться на рассылки».
- Текст: «Премьеры, события и начало продаж билетов —», затем принудительная новая строка **«в вашей почте.»**. Это отдельное уточнение пользователя.
- Поле «Ваш e-mail»: обязательное, `type=email`, autocomplete.
- Обязательный, изначально пустой checkbox согласия на обработку персональных данных и получение рассылок.
- Кнопка «Подписаться», примечание «Отписаться можно в любом письме».
- После дополнительной проверки по скриншоту пользователь попросил обычный шрифт как в меню. Теперь кнопка входа, заголовок и submit — **Engravers Gothic Regular 400**, не Bold. Обычный текст формы — Lato.
- Текст кнопок отцентрирован, оптически поднят на 3 px из-за метрик шрифта. Форма и размеры рамок сохранены.
- **Последняя правка: стрелка полностью удалена из кнопки и на desktop, и на mobile.** Не возвращать её из старых макетов.
- Кнопка входа: ширина контейнера, min-height 56 px. Submit: min-height 44 px, min-width 170 px на десктопе, полная ширина на телефоне.
- Закрытие: крестик, Escape, на desktop также фон. Возврат фокуса и позиции страницы. При открытии из мобильного меню после закрытия формы меню остаётся открытым.
- Форма работает как демонстрация: реальный сервис не подключён. Валидный ввод показывает **«В режиме просмотра подписка не оформляется»**. Почта никуда не отправляется. Не показывать выдуманное успешное оформление подписки.

- Статические HTML/CSS/JS без сборщика и фреймворка.
- CSS и JS имеют версии в URL для обновления кеша.
- Подписка инициализируется после `DOMContentLoaded`, когда мобильное меню афиши уже построено. Ранее обнаруживался баг с попыткой вставить кнопку до создания меню; исправлен.
- Native dialog удерживает фокус. При вложенном мобильном меню сохраняется и восстанавливается предыдущее состояние overflow.
- У обработчиков инертного превью есть исключение для элементов внутри формы подписки.
- `.superpowers/` в локальной рабочей копии — промежуточные скриншоты, локальные серверы, инструменты импорта/диагностики. Не добавлять всю папку в публичный репозиторий автоматически.

## Что остаётся демонстрацией / для будущего подключения

- Расписание — снимок исходной страницы, не синхронизируется с текущей афишей. В данных остались сентябрьские события.
- Покупка, кабинет, серверные фильтры, исходные переходы и аналитика не подключены. Раскрытие фильтра и checkbox работают визуально, но не как серверный поиск.
- Страница «Театр» отдельно не переделывалась в полноценную мобильную версию.
- Для рабочей подписки нужны сервис/endpoint НОВАТа и окончательные юридические ссылки/тексты. Текущая ссылка согласия ведёт к документам на сайте клиента.
- Официальные файлы брендбука действительно доступны для скачивания.
- После публикации при проверке использовать новую query-версию ссылки; старая вкладка может содержать кеш.
